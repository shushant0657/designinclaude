Free DESIGN.md template

DESIGN.md is an open format for describing a visual identity to AI design and coding agents. The top holds exact token values in YAML; the body explains why and how to use them. Drop it in your repo or your Claude skill and agents stop guessing.

Download DESIGN.md↓

The rules of the format

  • Sections are optional but must appear in this order: Overview, Colors, Typography, Layout, Elevation & Depth, Shapes, Components, Do's and Don'ts.
  • No duplicate headings or duplicate top-level YAML keys.
  • Reference tokens with braces, like {colors.primary}.
  • Component variants are separate keys, like button-primary and button-primary-pressed.
  • If you have Node, lint it: npx @google/design.md lint DESIGN.md (checks structure, references and contrast).

The template

---
version: alpha
name: <Product>
description: <one line>

  primary: "#0F3D2E"
  on-primary: "#FFFFFF"
  background: "#FBF7F0"
  surface: "#FFFFFF"
  text: "#13231C"
  text-muted: "#5E6B64"
  accent: "#F2A33A"
  border: "#E6DDCF"
  success: "#1F7A4D"
  warning: "#B86E00"
  error: "#B3261E"
typography:
  display: { fontFamily: "Inter", fontSize: 40px, fontWeight: 700, lineHeight: 44px }
  h1: { fontFamily: "Inter", fontSize: 24px, fontWeight: 700, lineHeight: 30px }
  body: { fontFamily: "Inter", fontSize: 15px, fontWeight: 400, lineHeight: 22px }
  label: { fontFamily: "Inter", fontSize: 14px, fontWeight: 600, lineHeight: 20px }
rounded:
  button: 12px
  card: 16px
  sheet: 24px
  chip: 999px
spacing:
  xs: 4px
  sm: 8px
  md: 16px
  lg: 24px
  xl: 32px
components:
  button-primary: { backgroundColor: "{colors.primary}", textColor: "{colors.on-primary}", typography: "{typography.label}", rounded: "{rounded.button}", height: 52px, padding: 16px }
  button-primary-pressed: { backgroundColor: "#0A2C21" }
  card: { backgroundColor: "{colors.surface}", rounded: "{rounded.card}", padding: 16px }
---

Questions

What is DESIGN.md?

An open, plain-text format (published by Google) that describes a product's design system to AI agents: exact tokens in YAML front matter and guidance in Markdown.

Does Claude understand DESIGN.md?

Yes. Claude reads it like any Markdown file. Put it in a skill or a project, and ask Claude to follow it when designing.
