How to put your design system into Claude

A skill is a folder of instructions Claude loads when it's relevant. Put your design system in one and every chat — yours or your team's — designs on brand without you pasting rules again. Here's what goes in it and how to build it.

What a design-system skill contains

  1. SKILL.md — when to use the skill, the rules, the Never list, an “Ask first” list and a 10-point self-check.
  2. tokens.css — colours, type, spacing and radii as CSS variables.
  3. Component recipes — button, input, card, list row: parts, variants, every state, which tokens.
  4. Voice rules — how buttons, errors, money and dates are written.
  5. DESIGN.md (optional) — the same system in Google's open DESIGN.md format, readable by any design or coding agent. Get the free template.

Why rules must be short and checkable

Claude follows concrete, testable instructions far more reliably than vague ones. “Main button: #4DA2FF, 48px tall, one per screen” works. “Use our brand nicely” wobbles. If you can't tick a rule ✓ or ✕, rewrite it.

Build it in five prompts

List every colour you see in the screenshots with its hex code. Then give each one a job: page background, card background, main text, secondary text, main button, success, warning, error.
Make a type scale: display, h1, h2, body, small and label — each with size, line height and weight.
Add a Never list to the design system. Then add 5 more items based on what would make a screen look generic compared to my app.
Make a specimen page as an artifact: every colour with its name and hex, every text size, the spacing scale and the five components in all their states.
Turn everything we decided into a design-system skill folder: a SKILL.md with the rules, the Never list and a 10-point self-check, plus a tokens.css file.

Test it

Open a brand-new chat with the skill switched on and send one line: “Design the settings screen.” If it looks like your app, you're done. If not, turn every difference into a new rule.

Questions

What is a Claude skill?

A skill is a folder with a SKILL.md file (and optional files like tokens.css) that Claude loads automatically when a task needs it. It works in the Claude app and in Claude Code.

Skill or Project — which should I use for a design system?

A skill travels with you across every chat and can be shared with a team. A Project is good for one body of work. For a design system, a skill is usually the better home.

What if I don't have a design system?

Start from references: pick 4–6 apps you love, say what you like in each, and ask Claude to propose a starting system you then make your own.
